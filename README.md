# Ticketing Warehouse

活动票务交易与运营离线数仓项目。

## 项目目标

完成数据库课程项目，并逐步扩展为数据开发与数据仓库作品。

## 计划实现的功能

- 活动、场馆、场次与座位管理
- 选座锁座与订单创建
- 模拟支付、取消与退款
- 电子票查看
- 并发防超卖与过期锁座释放
- 运营离线数仓与报表

第一版暂不包含检票与核销。

## 计划使用的技术

- PostgreSQL
- Python / FastAPI
- Docker Compose
- Spark / Hive Metastore
- Airflow

## 当前进度

已创建仓库，正在进行项目初始化与数据库设计。
